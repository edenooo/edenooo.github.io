## C. Swap Characters (2071) 67분 > 38분 (-29)

**왜 오래 걸렸는가? 풀이를 잘못 뽑았다가 한참 걸렸다.**

문자들의 순서는 안 중요하고 (A의 개수, B의 개수, C의 개수)만이 중요하다.

a → b, a → c, b → a, b → c, c → a, c → b 각각으로 몇 개 변환시킬지를 결정하는 건 $O(N^6)$이다.

여기서 a → b, b → a의 개수를 결정하면 3-cycle의 방향과 크기가 결정된다. 따라서 b → c, c → a의 개수를 결정하면 c → b, a → c의 개수도 자동으로 결정된다. 이제 $O(N^4)$이다. 

## D. Maximize Update (2440) 22분 < 29분

구간 DP를 하고 싶게 생겼다.

연산 역순으로, 색칠할 칸을 하나씩 점유해버린다고 생각하자.

dp[l][r] : [l,r]에 포함되는 interval들만 남아 있을 때 최대 개수의 interval을 선택하기

l ≤ m ≤ r인 m을 하나 골라서 점유해 버릴 수 있는지 판정하고, 가능하면 [l,m-1] & [m+1,r]이 남는다.

이제 $O(N^3)$에 풀린다.
