## E. XOR Partitioning (2423) 27분 < 46분

오렌지라기에는 쉬운데, unrated된 이유가 이 문제의 느린 채점 때문이었으니 과대평가인듯.

누적합 배열로 생각하는 게 편하다.

tot ≠ 0이면 쉽다. 각 subarray의 xor값 후보가 X=tot으로 고정되어서 $O(N)$ DP.

tot = 0이면, X의 후보가 S[i]중에 하나라서 각 후보에 대해 DP를 돌리면 $O(N^2)$로 TLE이다.

핵심 관찰: 특정 X값에 대한 문제를 풀 때에는 $S_i = X$ 또는 $S_i = 0$만 보면 된다.

0 → X → 0 → X → 0 처럼 상태전이가 되므로, X → X로의 상태 전이만 계산하면 amortized $O(N)$에 전체 문제가 해결된다.
